# Tarea 1: Control de Versiones con Git y GitHub

Este repositorio contiene la resolución del Taller de Git para la asignatura de Informática. El proyecto base es un simulador de Cajero Automático (ATM) programado en Python.

## Estructura del Repositorio
* `/26809449.py`: Código fuente del simulador de cajero.
* `/MANUAL.md`: Documentación detallada paso a paso sobre la configuración de Git.

## Objetivo
Demostrar el uso de ramas (`main` y `develop`), gestión de commits descriptivos y documentación técnica bajo estándares profesionales.
